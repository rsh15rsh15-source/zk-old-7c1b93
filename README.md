## Как смотреть

Открыть `index.html` в любом браузере — данные вшиты в файл, сервер и интернет не нужны (интернет потребуется только при переходе по ссылке на конкретный лот).

Фильтры: поиск по предмету/заказчику/номеру, площадка, регион, ядро/смежное, «приём открыт», «закрывается за 24 ч», «новые за сутки», диапазон цены и сортировка.

## Как обновляется

Файл пересобирается скриптом `collect.mjs` из локального хранилища `data/items.json`; прогон стоит на расписании (рабочие дни, каждые 3 часа). Публикация — `deploy-gh.mjs`: пересобирает дашборд, кладёт его в `site/index.html` и пушит в этот репозиторий, откуда GitHub Pages отдаёт страницу.

## Что означает «ядро» / «смежное»

- **ядро** — предмет закупки прямо про светильники, светодиодные изделия, наружное освещение, опоры, прожекторы, светотехнику;
- **смежное** — электротовары, кабель, электрика, монтаж, благоустройство: релевантно, но не по профилю напрямую.

Все данные — из открытых источников; страница лишь агрегирует публичные извещения.
